## 📞 Suporte Rápido

**Problema: Não consegue fazer deploy?**
- Leia DEPLOY_GUIDE.md
- Verifique os logs no Render
- Confirme que todos os arquivos estão no repositório

**Problema: Quer customizar?**
- Edite colors em styles.css
- Edite textos em index.html
- Edite funcionalidades conforme necessário

**Problema: Funciona localmente mas não no Render?**
- Certifique-se de fazer `git push`
- Render faz deploy do repositório, não da máquina local
