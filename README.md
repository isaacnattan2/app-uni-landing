# APP UNI Landing Page

Landing page moderna para a plataforma APP UNI - Compras, Mobilidade, Entregas e Soluções Urbanas.

## 🚀 Início Rápido

### Local
```bash
npm install
npm start
# Abra: http://localhost:3000
```

### Deploy Render
1. Push para GitHub
2. Render > New Web Service
3. Connect repositório
4. Build: `npm install`
5. Start: `npm start`

## 📂 Estrutura
```
public/          → index.html
src/css/         → styles.css
src/js/          → script.js
src/assets/      → imagens, fonts
config/          → deploy, .env
docs/            → documentação
```
